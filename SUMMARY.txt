--------------------------------------------------------------------------------
0. КРАТКО
--------------------------------------------------------------------------------
Существовавшие разрозненные скрипты разложены по директориям-доменам, добавлены
недостающие CRUD-скрипты строго по схеме БД. Создано ~82 Python-файла в едином
стиле {action}_{object}.py, с проверками CHECK/UNIQUE/FK/enum, подтверждениями
опасных операций и предварительной проверкой зависимостей (delete_guard).

ВАЖНО: lib/delete_guard.py, lib/ui.py, lib/db.py — ПРОВЕРЕНЫ, их API полностью
соответствует тому, как его используют сгенерированные скрипты. Сквозная
py_compile-проверка ВСЕХ файлов НЕ завершена (команда была отменена пользователем).

1. СОГЛАСОВАННЫЕ РЕШЕНИЯ (с пользователем)
--------------------------------------------------------------------------------
1) Формат файлов — ГРАНУЛЯРНЫЕ отдельные скрипты create_* / edit_* / delete_* /
   view_* (НЕ один manage_* с внутренним меню), для единообразия и точечного

4) countries и весь catalog — полный CRUD.
5) issued_tickets — полный CRUD.
6) Сервисные/опасные скрипты (деплой/очистка БД) вынесены в service/.

5. РЕАЛИЗОВАННЫЕ ПРОВЕРКИ СХЕМЫ (ключевые)
--------------------------------------------------------------------------------
  - events: CHECK venue_id ИЛИ online_url; age_rating enum; capacity >= 0
  - event_schedules: kind='once' -> start_at/recurrence; 'recurring' -> recurrence;
    utc_offset формата +HH:MM
  - event_documents: content ИЛИ url
  - cities/venues: диапазоны lat/lng, capacity>=0, UNIQUE(country/city, slug)
  - tickets: sold_count <= tickets_count, *_count >= 0
  - promo_codes: percent<=100, max_uses>0, used_count<=max_uses,
    valid_to>valid_from, code UNIQUE
  - orders/order_items/payments: amount >= 0, quantity > 0
  - issued_tickets: status='used' <-> checked_in_at NOT NULL (управляется кодом)
  - users: CHECK email ИЛИ phone
  - delete_*: вызывает delete_guard.collect_dependencies + report_dependencies
    (печатает CASCADE/SET NULL/RESTRICT и блокирует при RESTRICT/NO ACTION).
